# DS 2 – Reihenfolge zählt

**Ziel:** Die SuS erleben, dass der Agent Befehle exakt in der geschriebenen Reihenfolge abarbeitet
— erst gehen, dann drehen ist nicht dasselbe wie erst drehen, dann gehen.

## Ablauf (90 Minuten)

| Phase | Minuten | Inhalt |
|---|---|---|
| Story | 5 | Dani hat gestern „Geh los!" gesagt — nichts ist passiert |
| Konzept | 10 | Programm als Liste, Sequenz = Reihenfolge |
| Spiel | 45 | Aufgaben an der Station (Auftrag, Noch einer, Remix) |
| Check | 20 | Vorhersage-Übung, Parsons-Puzzle, Quiz |
| Spielstand | 5 | Drei Sätze: Was kann ich jetzt? |

5 Minuten Puffer bis zur vollen Doppelstunde.

## Was die Lehrkraft sagt und zeigt

Sag sinngemäß: „Der Agent liest sein Programm von oben nach unten, Zeile für Zeile. Er denkt
nicht mit — wenn die Reihenfolge falsch ist, geht er falsch. Das ist kein Fehler, das ist ein
Missverständnis, das man reparieren kann." Zeig einmal live: dieselben zwei Befehle in
vertauschter Reihenfolge geben ein anderes Ergebnis.

## Typische Fehler und Hilfen

- Zauberwort großgeschrieben (`Weg` statt `weg`).
- `agent.move` und `agent.place` vertauscht — der Agent legt Blöcke immer, nachdem er sich bewegt
  hat, nicht davor.
- Einrückung unter `def on_weg():` fehlt oder ist uneinheitlich.
- Nach `agent.turn(LEFT_TURN)` erwarten SuS, dass der Agent automatisch weiterläuft — es braucht
  eine eigene `agent.move`-Zeile danach.

## Lösungen

Auftrag (Station s02):
```python
def on_weg():
    agent.teleport_to_player()
    agent.set_item(GRASS, 64, 1)
    agent.move(FORWARD, 1)
    agent.place(BACK)
    agent.move(FORWARD, 1)
    agent.place(BACK)
    agent.turn(LEFT_TURN)
    agent.move(FORWARD, 1)
    agent.place(BACK)
player.on_chat("weg", on_weg)
```

Noch einer — 5 Blöcke, dann Ecke, dann 2 weitere:
```python

    agent.teleport_to_player()
```

Remix — Vorschlag, eigenes Muster (Buchstabe Z):
```python
def on_z():
    agent.teleport_to_player()
    agent.set_item(GRASS, 64, 1)
    agent.move(FORWARD, 1)
    agent.place(BACK)
    agent.move(FORWARD, 1)
    agent.place(BACK)

    agent.move(FORWARD, 1)

```

## Differenzierung

- **Auftrag:** `weg` in den Chat schreiben, drei Blöcke, eine Ecke.
- **Noch einer:** Fünf Blöcke, dann Ecke, dann zwei weitere.
- **Remix:** Ein eigenes Muster (z. B. Z oder U) mit Partner:in zeigen.
