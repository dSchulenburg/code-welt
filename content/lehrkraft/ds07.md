# DS 7 – Zahlen mit Namen

**Ziel:** Die SuS lernen die Variable kennen: eine Zahl mit einem Namen, einmal gesetzt, überall
in der Schleife genutzt. Sie ändern eine Brücke, indem sie nur diese eine Zahl anfassen.

## Ablauf (90 Minuten)

| Phase | Minuten | Inhalt |
|---|---|---|
| Story | 5 | Der Fluss trennt Nour und Dani von der Etappe Eisen — eine Brücke muss her |
| Konzept | 10 | Variable `laenge`, einmal gesetzt, von der Schleife genutzt |
| Spiel | 45 | Aufgaben an der Station (Auftrag, Noch einer, Remix) |
| Check | 20 | Zuordnung, Lückencode, Quiz |
| Spielstand | 5 | Drei Sätze: Was kann ich jetzt? |

5 Minuten Puffer bis zur vollen Doppelstunde.

## Was die Lehrkraft sagt und zeigt

Sag sinngemäß: „`laenge` ist eine Zahl mit einem Namen. Sie steht nur einmal oben im Programm —
und die Schleife darunter nutzt sie überall. Willst du eine andere Länge, änderst du **eine**
Zahl, nicht das ganze Programm." Zeig den Umschalter Blöcke/Python oben im Editor: Im Block ist
`laenge` ein eigener „Setze"-Block, im Python die Zeile `laenge = 5`. Beide zeigen dasselbe.

Weise vor dem Spiel auf die Schilder am Fluss hin: Beide Stellen, A und B, verlangen Blick nach
Süden. Der Grund: `agent.teleport_to_player()` startet den Agent mit der Blickrichtung der SuS.
Mit Blick nach Süden liegt das Wasser direkt vor der Goldmarke. Wer schräg steht, baut die Brücke
schräg in den Fluss. Wer nach Norden schaut, baut sie zurück zur Startzone.

## Typische Fehler und Hilfen

- Beim „Noch einer" wird eine Zahl **an der falschen Stelle** geändert — z. B. die `range`-Zahl in
  einer anderen Zeile statt der `laenge`-Zeile selbst. Zeig: Es gibt nur eine Stelle, an der die
  Zahl steht, alles andere liest nur `laenge`.
- Tippfehler im Variablennamen (`lange` oder `Laenge` statt `laenge`) — der Editor markiert das,
  aber SuS übersehen die Markierung leicht. Zusammen die Fehlermeldung lesen.
- Die SuS schaut beim Start nicht nach Süden (siehe Hinweis oben). Die Brücke landet dann nicht
  über dem Fluss. Erste Hilfe: neu hinstellen, so dass das Wasser direkt vorn liegt, `bruecke`
  erneut schreiben.

## Lösungen

Auftrag (Station s07) — Brücke an Stelle A, 5 Blöcke lang:
```python
def on_bruecke():
    laenge = 5
    agent.teleport_to_player()
    agent.set_item(PLANKS_OAK, 64, 1)
    for index in range(laenge):
        agent.move(FORWARD, 1)
        agent.place(DOWN)
player.on_chat("bruecke", on_bruecke)
```

Noch einer — Stelle B, Fluss 8 breit, nur `laenge` geändert:
```python
def on_bruecke():
    laenge = 8
    agent.teleport_to_player()
    agent.set_item(PLANKS_OAK, 64, 1)
    for index in range(laenge):
        agent.move(FORWARD, 1)
        agent.place(DOWN)
player.on_chat("bruecke", on_bruecke)
```

Remix — Vorschlag, andere Blockart:
```python
def on_bruecke():
    laenge = 5
    agent.teleport_to_player()
    agent.set_item(COBBLESTONE, 64, 1)
    for index in range(laenge):
        agent.move(FORWARD, 1)
        agent.place(DOWN)
player.on_chat("bruecke", on_bruecke)
```

## Differenzierung

- **Auftrag:** `bruecke` auf dem Goldblock an Stelle A schreiben, über die Brücke gehen, im Python
  die Zeile `laenge = 5` finden.
- **Noch einer:** Zum Goldblock an Stelle B gehen, nur `laenge` auf 8 ändern.
- **Remix:** Andere Blockart nehmen oder die Brücke zwei Blöcke breit bauen, einem Partner oder
  einer Partnerin zeigen.
