# DS 1 – Die neue Welt

**Ziel:** Die SuS verstehen, dass der Agent nur Code versteht und erst nach einem Zauberwort im
Chat loslegt. Sie ändern ihr erstes Programm (Zauberwort und Schrittzahl).

## Ablauf (90 Minuten)

| Phase | Minuten | Inhalt |
|---|---|---|
| Story | 5 | Ankunft in der Welt, Nour zeigt Dani den Agent |
| Konzept | 10 | Agent, Code Builder (Taste `C`), Zauberwort |
| Spiel | 45 | Aufgaben an der Station (Auftrag, Noch einer, Remix) |
| Check | 20 | Vorhersage-Übung, Parsons-Puzzle, Quiz |
| Spielstand | 5 | Drei Sätze: Was kann ich jetzt? |

5 Minuten Puffer bis zur vollen Doppelstunde.

## Was die Lehrkraft sagt und zeigt

Zeig kurz den Agent im Spiel (der kleine Roboter-Charakter neben dem Spawn). Sag sinngemäß: „Der
Agent hört nicht auf gesprochene oder getippte normale Sätze. Er reagiert nur auf ein Zauberwort
im Chat und macht dann genau das, was im Code steht." Öffne gemeinsam mit `C` den Code Builder.

Sag den **Play-Button** dazu, bevor die ersten Hände hochgehen: Der Code startet nicht von
selbst. Erst Play im Code Builder, dann das Zauberwort in den Chat.

## Typische Fehler und Hilfen

- **Kein Auto-Run:** Es wurde nie auf Play geklickt. Das Programm liegt im Editor, läuft aber
  nicht — der Chat bleibt still. Das ist die häufigste Ursache für „Ich tippe hi und nichts
  passiert" und die erste Frage, die du stellst.
- Zauberwort großgeschrieben (`Hi` statt `hi`) — der Chat-Vergleich reagiert nicht darauf.
- Agent steht weit weg — deshalb steht `agent.teleport_to_player()` als erste Zeile im Programm.
- Einrückung fehlt unter `def on_hi():` — ohne Einrückung meldet der Editor einen Fehler.

**Hinweis, kein Fehler:** Funktionsname und Zauberwort müssen nicht gleich heißen. Wer das
Zauberwort zu `hallo` ändert und die Funktion `on_hi` stehen lässt, hat ein funktionierendes
Programm — nur eins, das sich beim Lesen komisch anfühlt. Ruhig ansprechen, aber nicht als Fehler
anstreichen.

## Lösungen

Auftrag (Station s01):
```python
def on_hi():
    agent.teleport_to_player()
    agent.move(FORWARD, 1)
player.on_chat("hi", on_hi)
```

Noch einer — Zauberwort `hallo`, 3 Schritte statt 1:
```python
def on_hallo():
    agent.teleport_to_player()
    agent.move(FORWARD, 3)
player.on_chat("hallo", on_hallo)
```

Remix — Vorschlag, ein zweites, freies Zauberwort:
```python
def on_spring():
    agent.teleport_to_player()
    agent.move(UP, 1)
player.on_chat("spring", on_spring)
```

## Differenzierung

- **Auftrag:** `hi` in den Chat schreiben, Agent kommt und geht einen Schritt.
- **Noch einer:** Zauberwort zu `hallo` ändern, Schritte von 1 auf 3.
- **Remix:** Ein zweites, selbst erfundenes Zauberwort mit eigener Wirkung.
