# DS 11 – Sonst

**Ziel:** Die SuS lernen `else`: In jedem Durchlauf läuft genau einer der zwei Wege, nie beide.
Sie zählen Schritte und Löcher zusammen und ändern die Zahl direkt im Python-Code.

## Ablauf (90 Minuten)

| Phase | Minuten | Inhalt |
|---|---|---|
| Story | 5 | Löcher auf der Bahn — der Agent muss selbst entscheiden: gehen oder legen |
| Konzept | 10 | `if`/`else` als zwei Wege, Zählen: ein Schritt oder ein Block je Durchlauf |
| Spiel | 45 | Aufgaben an der Station (Auftrag, Noch einer, Remix) |
| Check | 20 | Lückencode, Fehlersuche, Quiz |
| Spielstand | 5 | Drei Sätze: Was kann ich jetzt? |

5 Minuten Puffer bis zur vollen Doppelstunde.

## Was die Lehrkraft sagt und zeigt

Tafelbild: „Ein Durchlauf = ein Schritt ODER ein Block." Sag sinngemäß: „Ist unten Boden, geht der
Agent einen Schritt. Sonst — `else` — legt er einen Block. Nie beides in einem Durchlauf." Zähl
mit der Klasse am Beispiel durch: Die Bahn hat 10 Felder, aber 4 davon sind Löcher. Jedes normale
Feld kostet einen Durchlauf (ein Schritt), jedes Loch kostet ebenfalls einen Durchlauf (ein
Block) — macht **10 + 4 = 14 Durchläufe** bis zum letzten Feld.

Zeig den Modus „Zahl in Python ändern": Im Editor auf Python umschalten, die Zahl in `range(10)`
durch `14` ersetzen, zurück auf Blöcke schalten — der `repeat`-Block zeigt jetzt die neue Zahl.
Beide Ansichten zeigen dasselbe Programm.

## Typische Fehler und Hilfen

- SuS lässt die Stationszahl `range(10)` stehen und wundert sich, dass der Agent nicht bis zur
  Wand kommt. Zurück zur Tafel-Rechnung: 10 Felder plus 4 Löcher sind 14, nicht 10.
- `if` und `else` vertauscht — der Agent legt dann Blöcke auf festem Boden und läuft über Löcher.
  Gemeinsam die Bedingung laut vorlesen: „Ist unten Boden — dann gehen. Sonst legen."
- `FORWARD` statt `DOWN` in der Bedingung (siehe Fehlersuch-Übung) — der Agent bleibt auf dem
  Goldblock stehen, weil vorn immer frei ist und die Bedingung nie wahr wird. Prüfen, was direkt
  vor dem Agent liegt (Luft), und was tatsächlich geprüft werden muss (der Boden unter ihm).

## Lösungen

Auftrag (Station s11) — Löcher füllen, `range(10)` reicht bewusst noch nicht:
```python
def on_loecher():
    agent.teleport_to_player()
    agent.set_item(PLANKS_OAK, 64, 1)
    for index in range(10):
        if agent.detect(AgentDetection.BLOCK, DOWN):
            agent.move(FORWARD, 1)
        else:
            agent.place(DOWN)
player.on_chat("loecher", on_loecher)
```

Noch einer — die richtige Zahl, nur `range` geändert:
```python
def on_loecher():
    agent.teleport_to_player()
    agent.set_item(PLANKS_OAK, 64, 1)
    for index in range(14):
        if agent.detect(AgentDetection.BLOCK, DOWN):
            agent.move(FORWARD, 1)
        else:
            agent.place(DOWN)
player.on_chat("loecher", on_loecher)
```

Remix — Vorschlag, andere Blockart:
```python
def on_loecher():
    agent.teleport_to_player()
    agent.set_item(COBBLESTONE, 64, 1)
    for index in range(14):
        if agent.detect(AgentDetection.BLOCK, DOWN):
            agent.move(FORWARD, 1)
        else:
            agent.place(DOWN)
player.on_chat("loecher", on_loecher)
```

## Differenzierung

- **Auftrag:** Auf dem Goldblock der Bahn Löcher starten, Blick nach Süden, `loecher` schreiben
  und beobachten, wo der Agent stehen bleibt.
- **Noch einer:** Auf Python umschalten, die Zahl in `range` auf 14 ändern, bis zur Wand kommen.
- **Remix:** Die Löcher mit einem anderen Block füllen, einem Partner oder einer Partnerin zeigen.
