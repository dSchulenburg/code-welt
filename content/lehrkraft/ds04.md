# DS 4 – Wiederholen

**Ziel:** Die SuS verstehen, wozu eine Schleife da ist: Sie schreiben Zeilen einmal, der Computer
wiederholt sie viele Male. Erste eigene Schleife (`for … range(10):`).

## Ablauf (90 Minuten)

| Phase | Minuten | Inhalt |
|---|---|---|
| Story | 5 | Nacht kommt, eine Mauer aus 10 Blöcken muss her |
| Konzept | 10 | Schleife, Zählen ab 0, Einrückung als Schleifenbauch |
| Spiel | 45 | Aufgaben an der Station (Auftrag, Noch einer, Remix) |
| Check | 20 | Vorhersage-Übung, Parsons-Puzzle, Quiz |
| Spielstand | 5 | Drei Sätze: Was kann ich jetzt? |

5 Minuten Puffer bis zur vollen Doppelstunde.

## Was die Lehrkraft sagt und zeigt

Sag sinngemäß: „Zehnmal dieselben zwei Zeilen zu schreiben ist mühsam. Dafür gibt es die
Schleife: Du schreibst die Zeilen einmal, der Computer wiederholt sie zehnmal." Zeig `for index
in range(10):` und betone, dass der Computer bei 0 zu zählen beginnt — 0 bis 9 sind zehn Runden.

## Typische Fehler und Hilfen

- Einrückung der zwei Rumpfzeilen fehlt oder ist ungleich tief — dann gehören sie nicht mehr zur
  Schleife.
- `range(10)` wird als „bis 10, also elf Runden" missverstanden — es sind genau zehn Runden,
  0 bis 9.
- Zauberwort großgeschrieben (`Mauer` statt `mauer`).
- Bei „Noch einer" wird nur die Zahl geändert, aber die neue Blockart (`agent.set_item(...)`)
  vergessen.

## Lösungen

Auftrag (Station s04):
```python
def on_mauer():
    agent.teleport_to_player()
    agent.set_item(COBBLESTONE, 64, 1)
    for index in range(10):
        agent.move(FORWARD, 1)
        agent.place(BACK)
player.on_chat("mauer", on_mauer)
```

Noch einer — 20 Blöcke, andere Blockart (Eiche):
```python
def on_mauer():
    agent.teleport_to_player()
    agent.set_item(PLANKS_OAK, 64, 1)
    for index in range(20):
        agent.move(FORWARD, 1)
        agent.place(BACK)
player.on_chat("mauer", on_mauer)
```

Remix — Vorschlag, zwei Mauern mit Lücke dazwischen:
```python
def on_mauer():
    agent.teleport_to_player()
    agent.set_item(COBBLESTONE, 64, 1)
    for index in range(4):
        agent.move(FORWARD, 1)
        agent.place(BACK)
    agent.move(FORWARD, 2)
    for index in range(4):
        agent.move(FORWARD, 1)
        agent.place(BACK)
player.on_chat("mauer", on_mauer)
```

## Differenzierung

- **Auftrag:** `mauer` in den Chat schreiben, 10 Blöcke nachzählen.
- **Noch einer:** Zahl auf 20 ändern, andere Blockart nehmen.
- **Remix:** Zwei Mauern mit einer Lücke dazwischen bauen.
