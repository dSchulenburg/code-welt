# DS 5 – Schleife in der Schleife

**Ziel:** Die SuS verschachteln zwei Schleifen: Die innere baut eine Reihe, die äußere wiederholt
die Reihe und geht dabei eine Ebene hoch — aus der Mauer wird eine Wand.

## Ablauf (90 Minuten)

| Phase | Minuten | Inhalt |
|---|---|---|
| Story | 5 | Die Mauer ist nur eine Reihe hoch — Dani will eine echte Wand |
| Konzept | 10 | Verschachtelte Schleifen, innen die Reihe, außen die Ebenen |
| Spiel | 45 | Aufgaben an der Station (Auftrag, Noch einer, Remix) |
| Check | 20 | Vorhersage-Übung, Parsons-Puzzle, Quiz |
| Spielstand | 5 | Drei Sätze: Was kann ich jetzt? |

5 Minuten Puffer bis zur vollen Doppelstunde.

## Was die Lehrkraft sagt und zeigt

Sag sinngemäß: „Eine Schleife kann in einer anderen Schleife stehen. Die innere Schleife baut
eine Reihe von sechs Blöcken. Die äußere Schleife wiederholt das dreimal und geht jedes Mal eine
Ebene hoch." Zeig die zwei Einrückungsstufen im Code nebeneinander.

## Typische Fehler und Hilfen

- Einrückungstiefe von innerer und äußerer Schleife vertauscht.
- Nach den zwei Drehungen `agent.turn(LEFT_TURN)` **fehlt ein Schritt vorwärts** — ohne ihn steht
  der Agent neben der zuletzt gebauten Reihe, und die Wand wird zur Treppe statt gerade zu
  bleiben. Das ist der wichtigste Stolperstein dieser Stunde, siehe Lösung unten.
- **Eine mittlere Reihe kürzer gemacht → die nächste Reihe verschiebt sich.** Der Agent hört dann
  früher auf und startet die nächste Reihe an einer anderen Stelle. Nur die **oberste** Reihe darf
  kürzer sein, weil danach keine Reihe mehr folgt. Genau daran hängt der Remix dieser Stunde.
- Zwei Zahlen bei „Noch einer" ändern (Breite **und** Höhe), nicht nur eine.
- Zauberwort großgeschrieben (`Wand` statt `wand`).

## Lösungen

Auftrag (Station s05), **korrigiert nach dem Review vom 03.09.2026** — ohne das zusätzliche
`agent.move(FORWARD, 1)` nach den zwei Drehungen entsteht eine versetzte Treppe, keine Wand:
```python
def on_wand():
    agent.teleport_to_player()
    agent.set_item(COBBLESTONE, 64, 1)
    for index in range(3):
        for index2 in range(6):
            agent.move(FORWARD, 1)
            agent.place(BACK)
        agent.move(UP, 1)
        agent.turn(LEFT_TURN)
        agent.turn(LEFT_TURN)
        agent.move(FORWARD, 1)
player.on_chat("wand", on_wand)
```

Noch einer — 8 Blöcke breit, 4 hoch:
```python
def on_wand():
    agent.teleport_to_player()
    agent.set_item(COBBLESTONE, 64, 1)
    for index in range(4):
        for index2 in range(8):
            agent.move(FORWARD, 1)
            agent.place(BACK)
        agent.move(UP, 1)
        agent.turn(LEFT_TURN)
        agent.turn(LEFT_TURN)
        agent.move(FORWARD, 1)
player.on_chat("wand", on_wand)
```

Remix — **die Zinne:** Die oberste Reihe wird kürzer, die Wand bekommt oben eine Stufe wie eine
Burgmauer. Der Trick ist, die äußere Schleife eine Runde kürzer laufen zu lassen und die letzte,
kurze Reihe danach einzeln zu bauen. Zwei volle Reihen à 6 Blöcke, obendrauf eine Reihe aus 3:
```python
def on_wand():
    agent.teleport_to_player()
    agent.set_item(COBBLESTONE, 64, 1)
    for index in range(2):
        for index2 in range(6):
            agent.move(FORWARD, 1)
            agent.place(BACK)
        agent.move(UP, 1)
        agent.turn(LEFT_TURN)
        agent.turn(LEFT_TURN)
        agent.move(FORWARD, 1)
    for index3 in range(3):
        agent.move(FORWARD, 1)
        agent.place(BACK)
player.on_chat("wand", on_wand)
```
Wer stattdessen einfach die innere Zahl in einer mittleren Runde kleiner setzt, bekommt keine
Zinne, sondern eine verschobene Wand — siehe „Typische Fehler". Das ist eine gute Stelle zum
Ausprobieren-Lassen: erst falsch, dann erklären.

## Differenzierung

- **Auftrag:** `wand` in den Chat schreiben, 6 breit und 3 hoch nachzählen (18 Blöcke).
- **Noch einer:** Auf 8 breit und 4 hoch ändern — zwei Zahlen anpassen.
- **Remix:** Die oberste Reihe kürzer machen (Zinne), einem Partner/einer Partnerin zeigen.
