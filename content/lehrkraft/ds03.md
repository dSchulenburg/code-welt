# DS 3 – Zauberwörter

**Ziel:** Die SuS verstehen, dass ein Wort im Chat ein Ereignis ist und jedes Zauberwort sein
eigenes Programm startet. Boss-Check Holz am Ende der Stunde.

## Ablauf (90 Minuten)

| Phase | Minuten | Inhalt |
|---|---|---|
| Story | 5 | Dani will einen Weg und einen Turm — zwei Zauberwörter |
| Konzept | 10 | Ereignis, mehrere Hut-Blöcke nebeneinander |
| Spiel | 45 | Aufgaben an der Station (Auftrag, Noch einer, Remix) |
| Check | 20 | Vorhersage, Parsons, Quiz — dann der **Boss-Check Holz „Das L"** |
| Spielstand | 5 | Drei Sätze: Was kann ich jetzt? |

5 Minuten Puffer bis zur vollen Doppelstunde. Der Boss-Check braucht den größeren Teil der
Check-Phase. Wer mit den Stationsübungen früher fertig ist, fängt schon in der Spielphase damit
an — die letzten fünf Minuten gehören dem Spielstand.

## Was die Lehrkraft sagt und zeigt

Sag sinngemäß: „Ein Wort im Chat ist ein Ereignis — etwas passiert im Spiel. Jedes Zauberwort hat
seinen eigenen Hut-Block mit eigenem Programm darunter. Tippst du erst `weg`, dann `turm`, laufen
beide Programme, eins nach dem anderen." Zeig beide Zauberwörter live nacheinander.

Erinnere vor dem Boss-Check an die Eck-Regel aus DS 2: Nach dem Drehen legt der Agent zuerst den
Eck-Block, erst danach geht es in die neue Richtung.

## Typische Fehler und Hilfen

- Beide Programme werden versehentlich unter einen Hut-Block geschrieben — jedes Zauberwort
  braucht eine eigene `def`-Funktion und eine eigene `player.on_chat(...)`-Zeile.
- Turm-Höhe falsch gezählt: pro zusätzlichem Block braucht es ein `agent.place(FORWARD)` **und**
  ein `agent.move(UP, 1)` davor.
- Einrückung der Rumpfzeilen nach `def on_turm():` fehlt.
- In `player.on_chat("turm", on_turm)` steht ein Funktionsname, den es nicht gibt (Tippfehler,
  oder die Funktion wurde umbenannt) — dann startet nichts. Der Name muss zur `def`-Zeile passen;
  mit dem Wort im Chat muss er **nicht** übereinstimmen.
- Ein Zauberwort mit Umlaut (`brücke`) im Remix: **Zauberwörter ohne Umlaut schreiben**, sonst
  passt das getippte Wort im Chat nicht zum Wort im Code. Im Kurs heißt es deshalb `bruecke`.

## Lösungen

Auftrag (Station s03):
```python
def on_weg():
    agent.teleport_to_player()
    agent.set_item(GRASS, 64, 1)
    agent.move(FORWARD, 1)
    agent.place(BACK)
    agent.move(FORWARD, 1)
    agent.place(BACK)
player.on_chat("weg", on_weg)

def on_turm():
    agent.teleport_to_player()
    agent.set_item(STONE, 64, 1)
    agent.place(FORWARD)
    agent.move(UP, 1)
    agent.place(FORWARD)
    agent.move(UP, 1)
    agent.place(FORWARD)
player.on_chat("turm", on_turm)
```

Noch einer — Turm 5 Blöcke hoch:
```python
def on_turm():
    agent.teleport_to_player()
    agent.set_item(STONE, 64, 1)
    agent.place(FORWARD)
    agent.move(UP, 1)
    agent.place(FORWARD)
    agent.move(UP, 1)
    agent.place(FORWARD)
    agent.move(UP, 1)
    agent.place(FORWARD)
    agent.move(UP, 1)
    agent.place(FORWARD)
player.on_chat("turm", on_turm)
```

Remix — Vorschlag, drittes Zauberwort `bruecke` über eine Lücke:
```python
def on_bruecke():
    agent.teleport_to_player()
    agent.set_item(STONE, 64, 1)
    for index in range(5):
        agent.move(FORWARD, 1)
        agent.place(DOWN)
player.on_chat("bruecke", on_bruecke)
```

## Differenzierung

- **Auftrag:** `weg`, dann `turm` in den Chat schreiben, beide Bauten vergleichen.
- **Noch einer:** Turm auf 5 Blöcke Höhe ändern.
- **Remix:** Ein drittes Zauberwort `bruecke` erfinden, das eine Lücke überbrückt.

## Boss-Check-Bewertung: „Das L" (gradeMax 100)

Aufgabe (ohne Tipp-Leiter): Der Agent legt ein L aus Blöcken — 4 Blöcke geradeaus, dann eine
Ecke, dann 2 Blöcke. Abgabe per Share-Link plus drei Sätze: Was macht dein Programm? Warum ist
die Reihenfolge wichtig? Was war schwer?

**Nachgerechnet (Eck-Regel):** Vier Paare bauen die Linie, dann kommt die Drehung, dann folgen
**drei** Paare — das erste davon legt den Eck-Block, der noch in der langen Linie liegt. Das
fertige L hat **7 Blöcke**: die lange Linie ist 5 Blöcke lang (die Ecke zählt dazu), der Arm ist
2 Blöcke lang. Ausmaß 5 × 3 Felder.

Beispiel-Lösung (einer von mehreren möglichen Wegen):
```python
def on_l():
    agent.teleport_to_player()
    agent.set_item(COBBLESTONE, 64, 1)
    for index in range(4):
        agent.move(FORWARD, 1)
        agent.place(BACK)
    agent.turn(LEFT_TURN)
    for index in range(3):
        agent.move(FORWARD, 1)
        agent.place(BACK)
player.on_chat("l", on_l)
```

Punkteraster:
- **60** — Programm läuft, das L ist im Grundsatz erkennbar (Anzahl oder Ecke nicht ganz genau),
  Text unvollständig.
- **80** — L korrekt: 7 Blöcke, Linie 5 mit Ecke, Arm 2; im Programm 4 Paare, Drehung, 3 Paare.
  Alle drei Fragen im Text sinnvoll beantwortet.
- **100** — wie 80, zusätzlich eine eigene Ergänzung (z. B. andere Blockart, längeres L) oder eine
  Erklärung, die den Sequenz-Begriff aus DS 2 aufgreift.

Ein L mit 6 Blöcken ist der häufigste Fall knapp unter 80: Nach der Drehung wurden nur zwei
Paare statt drei geschrieben, der Arm hat dann nur einen Block. Das ist genau die Eck-Regel aus DS 2 — im Feedback darauf
zeigen, nicht die Zahl allein anstreichen.

Der Kursabschluss der Aufgabe zählt **bei Abgabe** (Share-Link + Text eingereicht), unabhängig
von der Punktzahl — das Badge „Holz" hängt am Abschluss aller Checks und dieser Abgabe, nicht an
einer Mindestpunktzahl.
